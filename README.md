# ITIA // THE LADDER & WORD FORGE SUITE
> *I Think It's Art* ([@IThinkItsArt](https://twitter.com/IThinkItsArt))

An avant-garde dark aesthetic gaming suite featuring real-time 2D canvas physics, procedural Web Audio API synthesis, and generative fine art unlocks.

---

## 🎮 Game Modes

### 1. ✦ Word Forge (Suika Physics Drop)
- Drop glowing letter spheres into the containment vessel.
- Collide and merge identical runes to evolve them up the sequence:
  ```
  [ I ] + [ I ]       ➔ [ T ] (Crossbeam)
  [ T ] + [ T ]       ➔ [ I ] (Golden Pillar)
  [ I ] + [ I ]       ➔ [ A ] (Genesis Apex)
  [ A ] + [ A ]       ➔ [ ITIA ] (✦ THE ART SINGULARITY ✦)
  [ ITIA ] + [ ITIA ] ➔ ✦ COSMIC TRANSCENDENCE ✦ (+5,000 PTS & Screen Wipe)
  ```
- Unlocks generative fine art pieces in the permanent **ITIA Collection**.

### 2. ⚡ Ladder of Destiny (Ghost Leg / Amidakuji / 사다리타기)
- Japanese *Amidakuji* / Korean *Sadari-tagi* fate descent.
- **Interactive Rung Builder**: Click anywhere between paths to add/remove rungs on the fly.
- **Batch Contender Importer**: Paste lists of Twitter handles, Discord names, or Ethereum wallet addresses.
- **Suspense Modifiers**: Toggle Fog of War (blind rungs) and dynamic tension cameras.
- **Ceremony Card**: Shareable results summary for community giveaways and tournaments.

### 3. ▲ The Mad Ascent (Infinite Reflex Climber)
- Fast-paced arcade reflex test.
- Scale the monumental **I · T · I · A** letter architecture while dodging cracked rungs and outclimbing the thermal disintegrator.
- Hyper Overdrive combo multipliers and altitude score ranking.

### 4. ◈ Risk Ladder (The Multiplier Tower)
- 15-rung high-stakes tower from `1.1x` to `500x ART GOD`.
- Weigh survival odds against climbing higher or cashing out.

## 🚀 Getting Started

No build tools or external dependencies required!

### Run Locally
Open `index.html` directly in any modern web browser, or serve via HTTP:
```bash
python -m http.server 3000
# or
npx serve .
```
Navigate to `http://localhost:3000`.

### Hotkeys
- `1` / `2` / `3` / `4`: Switch game modes
- `M`: Toggle procedural audio (Mute/Unmute)
- `Space`: Drop sphere / Start / Jump gap
- `Esc`: Close open modals

## 🛠️ Built With
- **HTML5 & Vanilla CSS3**: Custom design system, glassmorphism, responsive grid layouts.
- **HTML5 Canvas (2D)**: Real-time circle collision physics and particle systems.
- **Web Audio API**: 100% procedural sound synthesis (chimes, sub-bass drops, electric zaps, ambient cyber drone).
